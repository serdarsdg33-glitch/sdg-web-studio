FAQ

Before we begin.

Short answers to the questions that usually affect price, delivery and project scope.

What do you need from me to start?

A short description of your goal, the pages or features you need, examples you like and any content you already have. If the scope is unclear, I will help turn it into a practical project list.

Are the listed prices final?

No. They are starting prices for clearly defined scopes. You receive a written quote before work begins, so the deliverables and total project price are clear.

Can you improve an existing website?

Yes. I can review and fix responsive problems, layout issues, JavaScript errors and visual inconsistencies without rebuilding everything when the current structure is usable.

Do you support multilingual and RTL layouts?

Yes. Language switching and right-to-left layouts for Persian and Arabic can be included when they are part of the agreed scope.
